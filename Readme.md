This is an app concept that will serve as a work hour tracker. When completing work with clients and you do custom jobs, you can charge per hour, so if a client asks where you get a number of hours from, this app will record how many hours work, when you started and stopped, you can pause it and continue the timer, and you can also add descriptions and pictures to show what was worked on. It can be used for employees as well just for some time tracking.
